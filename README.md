# 🐾 宠物小屋（微信小游戏）

一款以**真实时间**为节奏的养宠小游戏：初始可以在 **小猫、小狗、小猪、小牛、小羊、小鸡** 六种里选一种或多种来养，
它们住在小屋里，你需要每天喂食、喂水、让它们休息、多抚摸它们；也可以上传自己的照片，
渲染成专属 3D 形象成为新的宠物（照片伙伴也要先选定一种物种，才能和同种伙伴一起生活、繁衍）。

> 游戏时间与现实时间一致 —— 就算关掉游戏，宠物也会继续变饿、变渴、变困。

---

## 玩法规则

| 操作 | 说明 |
| --- | --- |
| 🍖 喂食 | 点底部「喂食」，宠物会走到粮碗旁吃饭，饱食度恢复 |
| 💧 喝水 | 点底部「喝水」，宠物会走到水碗旁喝水，渴度恢复 |
| 😴 休息 | 点底部「休息」，宠物打盹 4 秒，精力恢复 |
| 🤗 抚摸 | **点按或滑动宠物**，宠物会冒出爱心、开心地跳起来 |
| 🐾 六种宠物 | 初始可领养 **小猫 / 小狗 / 小猪 / 小牛 / 小羊 / 小鸡**（可多选）；每种有自己的窝（圆顶或三角顶，按物种配色），休息时回自己的窝 |
| ✏️ 起名 | 开始界面可给每只宠物起名；游戏中点状态卡可改名 |
| 📷 照片宠物 | 点「添加」→ 选择照片 → **选物种（六选一，必选）** → 起名领养；照片伙伴也会长所选物种的耳朵/角/鸡冠等器官 |
| 🏠 窝 | 每个物种按养的宠物数量自动摆窝（同一物种合用一个宽窝），宠物休息时会回自己的窝 |
| ⚽ 足球 | 房间有足球，宠物会追球踢着玩；多只宠物会互相追逐打闹、跑酷、散步 |
| 🚽 猫砂盆 | 宠物每天约去 3 次猫砂盆：尿尿渴度 -10%，拉臭饱食度 -10%；盆会变脏（脏度条可见），**点一下猫砂盆铲屎**，一天不铲宠物睡不好觉，三天精力耗尽 |
| 🍚 碗 | 粮碗水碗初始是空的，**点一下碗**就能添粮 / 添水；碗里的粮水会随时间消耗，**一天耗完**，第二天要再点一次（宠物吃/喝也会扣存量） |
| ⚖️ 体重 | 初始 3 斤，每年约涨 3 斤（按天均摊），宠物体型会随重量变大 |
| ♂♀ 公母 | 领养时**手动选公母**（不选就随机）；同种一公一母养满一年后，可到后台点"**配对生育**"手动选择配哪两只，生 1~4 只小宝宝（新生命公母随机） |
| 💀 死亡 | 粮 / 水 / 精力任意一项降到 **0%** 宠物就会离开，只剩一座刻着名字的墓碑（点墓碑可领养新的） |

- 粮、水、精力三项都按 **3 天（72 小时）** 从 100% 衰减到 0%（真实时间，状态卡显示百分比）
- 任意一项归零即死亡：饿死 / 渴死 / 过度疲惫，弹窗会说明原因
- 又饿又渴又困时宠物会难过，头顶出现「饿 / 渴」气泡，精力低会自动睡觉
- 宠物多了之后顶部状态卡可以**左右滑动 / 点两侧箭头**查看
- 宠物每天的时间按权重分配：玩足球约 10%、跑酷约 10%、多只追逐打闹约 10%、漫无目的散步约 20%、其余约 50% 休息（休息时回窝或就地趴着）

## 两种运行方式

### 方式一：浏览器直接试玩（推荐先玩一下）

直接双击打开 `preview.html`（或浏览器打开），无需任何环境。

演示参数（URL 后追加）：
- `?demo=1` 跳过起名，直接进入小屋
- `?demo=1&day=73` 模拟 73 小时没照料（三项耗尽），查看墓碑场景
- `?demo=1&addpet` 直接查看领养界面
- `?demo=1&age=365` 模拟已养 1 年（体重 6.0 斤，可触发繁殖）
- `?demo=1&litter=1` 立即安排宠物如厕（看猫砂盆效果）
- `?demo=1&g1=m&g2=f` 指定前两只宠物的公母（m=公 / f=母）
- `?demo=1&pets=4&age=365&g1=m&g2=f&g3=m&g4=f` 凑一公一母同种养满一年 → 几秒后生一窝
- `?demo=1&bowlHr=0.006` 碗加速消耗（约 20 秒耗完，看"一天耗完再点"效果）
- `?demo=1&dirt=100` 猫砂盆初始脏满（看"该铲屎啦"和臭气效果）
- `?demo=1&admin=1` 打开后台面板（时间快进：+1 / +7 / +30 / +365 天，满一年公母自动生小猫）
- 主界面右上角 ⚙ 按钮随时可打开后台面板（快进按"正常照料"模拟：宠物不会饿死，体重随年龄涨，满一年的公母自动生小猫）
- 后台面板会直接告诉你当前为什么不能生（年龄还差几天 / 上次生产冷却还剩几天 / 缺公或母）；快进一年时上次生产的冷却时间也会同步过一年

### 方式二：微信开发者工具运行（真·微信小游戏）

1. 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（稳定版即可）
2. 打开开发者工具 →「导入项目」
3. 目录选择本文件夹 `wechat-pet-game`，AppID 选择「测试号」（游客模式）或你自己的小游戏 AppID
4. 点击「编译」，即可在模拟器 / 真机预览中游玩

### 发布上线（可选）

在微信公众平台注册「小游戏」类目账号 → 开发者工具中填自己的 AppID →
「上传」代码 → 在公众平台提交审核 → 审核通过后发布。
（照片宠物功能不需要任何服务器，所有数据都保存在用户本地。）

## 数据与隐私

- 照片只做本地处理（居中裁剪、采样主色、压缩为 160×160 贴图），**不会上传**
- 存档保存在本地（微信小游戏 Storage / 浏览器 localStorage）
- 清除本地数据即可重置游戏

## 常见问题

- **为什么宠物变难过了？** 饿（饱食度低）或渴（渴度低）了，去喂食 / 喂水
- **墓碑还能复活吗？** 不能，点墓碑可以「领养新的」同款宠物
- **改时间会怎样？** 以设备当前时间为准；往前改时间只会让衰减暂停
- **照片宠物怎么不像我？** 它是「照片方块 + 小脑袋」的 Q 版 3D 形象，
  贴图用的就是你的照片
